Gemeinsame Speicherung

Die veröffentlichte Seite kann Einträge nicht von selbst behalten. Einmalig wird ein GitHub-Schlüssel angelegt, der nur dieses Repository beschreiben darf. Schülernamen werden vorher verschlüsselt.

  1. Auf GitHub: Profil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nur dieses Repository auswählen. Unter Contents die Berechtigung Read and write setzen, den Token erzeugen und kopieren.
  3. Owner, Repository und Token unten eintragen. Der Token bleibt in diesem Browser. Auf jedem weiteren Gerät dieselben drei Werte einmal eintragen.

Das bisherige Passwort steht in der alten Datei auf GitHub. Bitte ein neues gemeinsames Passwort festlegen und es nur an Lehrkräfte weitergeben.
