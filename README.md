# Nachsitzplan

Gemeinsame Nachsitz-Liste für Lehrkräfte. Die Seite wird über GitHub Pages geöffnet. Einträge liegen verschlüsselt in der Nextcloud im Ordner `Nachsitzplan` und sind nach der Anmeldung auf allen Geräten sichtbar.

## Bedienung

1. Seite öffnen und mit dem gemeinsamen Benutzernamen und Passwort anmelden.
2. Beim ersten Mal ein neues gemeinsames Passwort festlegen und es nur an Lehrkräfte weitergeben.
3. Name eintragen, Nachsitz hinzufügen, erledigen, Elternvermerk setzen oder löschen.

**Statistik** zählt gleiche Namen zusammen. **Sicherung** lädt eine Kopie herunter. Vor längeren Ferien eine Sicherung speichern.

## Datenschutz

- Die Seitenadresse ist öffentlich. Wer sie kennt, sieht die Anmeldeseite.
- Schülernamen liegen verschlüsselt in der Nextcloud. Ohne das gemeinsame Passwort ist die Datei nicht lesbar.
- Die Seite nicht auf der Schulhomepage verlinken.
- Erledigte Einträge löschen, wenn sie nicht mehr gebraucht werden.
